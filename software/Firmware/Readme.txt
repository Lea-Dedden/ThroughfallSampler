# main.ccp Projekt for PlatformIO

To use the firmware, you must flash the Arduino MKZ Zero bootloader onto the SAMD controller.

The best way to do this is to use the Atmel AVR ICE debugger. You can burn the bootloader using the Arduino IDE.
You can also flash the software after including all the libraries.

https://www.microchip.com/en-us/development-tool/atatmel-ice
